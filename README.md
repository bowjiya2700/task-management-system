# Task Management Dashboard

A responsive task management web application designed to help users
create, organize, track, and manage their daily tasks through a
simple and user-friendly dashboard.

## 📌 Features

- User Login and Registration
- Dashboard with task statistics
- Create and manage tasks
- Separate My Tasks and Vital Tasks
- Task Categories
- Task status tracking
- Daily task progress
- Weekly progress tracking
- Calendar view
- Search functionality
- Notification indicator
- User profile section
- Settings page
- Help section
- Responsive dashboard layout

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.8
- Font Awesome 7.3.1

### Tools
- Visual Studio Code
- Git
- GitHub
